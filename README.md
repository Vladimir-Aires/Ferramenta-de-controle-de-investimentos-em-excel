<h2>Uso do VF</h2>
<p>
  O Valor Futuro (VF) é uma fórmula do excel baseada em juros compostos que foi usada para verificar o patrimônio acumulado.
</p>
<br>
<h2>Uso do PROCV</h2>
<div>
  <p>
  O PROCV é a fórmula que foi usada para definir dinamicamente o percentual de distribuição do investimento em diferentes tipo de fundos, conforme o perfil do investidor.
